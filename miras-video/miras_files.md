# MIRAS — montaj faylları

| Fayl | Nədir |
|---|---|
| `miras_final_1080x1920.mp4` | Final film: 45 s, 1080×1920, 30 fps, H.264 + AAC, səs səviyyəsi təxminən −14 LUFS |
| `miras_animatic_9x16.mp4` | Oynadıla bilən animatik (540×960). Üstdə kadr nömrəsi, vaxt, kamera, səs qeydi və mənbə işarəsi |
| `miras_storyboard.md` / `miras_storyboard.png` | Vaxt kodlu storyboard və hər kadrdan bir görüntü |
| `miras_vo_script.md` | Səsləndirmə mətni, vaxt kodları və rejissor qeydləri |
| `miras_subtitles.srt` | Subtitrlər (SRT) |
| `audio/miras_vo.wav` | Yalnız səs (VO), 45 s zaman xəttində |
| `audio/miras_music.wav` | Yalnız musiqi (az notlu piano + pad, sintez) |
| `audio/miras_sfx.wav` | Yalnız effektlər: qapaq, hava, kağız, toxunuş |
| `audio/miras_mix.wav` | Final miks (səviyyəsi normallaşdırılıb) |
| `scene/index.html` + `scene/assets/` | Filmin mənbə kodu: kadrlar, kamera, vaxtlar və vizual fayllar |

Peşəkar diktorla əvəz etmək üçün yeni səs faylını `miras_vo_script.md`-dəki vaxt kodlarına uyğun yazdırmaq kifayətdir. Sonra eyni musiqi və effektlərlə yenidən miks edilir.
